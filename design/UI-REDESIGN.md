# 链取（LinkFetch）UI 重设计文档

> 版本：v1（评审稿，未实施）
> 范围：**只改 UI 与交互，不改任何功能逻辑**（解析 / 保存 / 历史 / 设置能力全部保留）
> 目标：简洁、优雅、美观 —— 从「蓝色四平八稳的工具感」升级为「克制的、当代审美的精致工具感」

---

## 1. 现状评估

现有 UI 已有扎实的设计功底（间距 4 的倍数体系、圆角嵌套规则、卡片描边、语义色分层都做得很好），
主要问题不在细节而在**整体气质与信息密度**：

| 问题 | 表现 | 影响 |
| --- | --- | --- |
| 品牌色大面积铺开 | 首页 Hero 一整块蓝色渐变横幅 | 首屏被一块 40dp+ 高的大色块吃掉，工具感强、留白少 |
| 信息重复表达 | Hero 副标题、平台光晕、页脚平台列表 → 同一屏「支持 4 平台」说了三遍；结果页 TypeTag 与网格重复 | 首屏「信息尾巴」长，扫一眼要过滤噪音 |
| 层级过于平均 | 首页从上到下：横幅 → 提示条 → 输入卡 → 记录 → 页脚，全是 16dp 卡片化块 | 缺一个「视觉锚点」，用户不知道先看哪 |
| 深色公平但活力不足 | 配色是标准 Slate + Blue | 缺少品牌记忆点，与大量同质工具 App 难以区分 |
| 反馈偏「盒子化」 | 所有状态都包进带描边带阴影的卡片 | 思考过程被框限制，读起来像「文档」而非「浏览」 |

> 结论：**体系是健康的，需要的是「降噪 + 定制感」**，不是推翻重来。

---

## 2. 设计目标与原则

1. **一个屏幕一个焦点**：每屏只留一个主行动（首页 = 输入解析；结果页 = 保存；历史 = 浏览/管理；设置 = 配置）。
2. **品牌色只用在「动作与被选择」上**：填充蓝只给按钮、选中态、进度；背景回到中性。
3. **图片即版式**：继续「相册式」思路，让媒体内容成为页面主体，装饰让位。
4. **少一层容器，多一分留白**：能用文字层级解决的就不加卡。
5. **定制感**：统一的图形语言（圆角胶囊、平台色小彩点、Link 图标符号复用），让 App 看起来「有设计」，而非「用了 Material 默认」。

---

## 3. 全局设计令牌（新增/微调，不破坏现有体系）

现有 `Spacing` / `Radii` / `Type` 保持不变，仅做增量：

| Token | 变更 | 用途 |
| --- | --- | --- |
| `surfaceTinted`（新增） | 浅 `Slate100` / 深 `Slate800` 的「淡层」 | 输入区、设置分组背景，替代部分描边卡 |
| 主按钮圆角 | 保持 `pill`，但高度统一 48dp 舒适高度 | 行动按钮的「一致性」 |
| 平台彩点（新增图形） | 8dp 实心圆点，配平台色 | 替代/补充 PlatformBadge，用于列表与输入区，降低视觉重量 |
| Hero 渐变（重设计） | 保留蓝色语言，改为**细线性渐变 + 更低高度** | 块感变「条感」 |

> 颜色语义：平台色只出现在「标识身份」；品牌蓝只出现在「动作与选中」；中性色负责结构。
> 规则清单（延续现有约定，不新增第三种含义）。

## 4. 各屏「前 → 后」对比与改动明细

### 4.1 首页 Home

**现状（Before）**
- 40dp+ 蓝色渐变 Hero 横幅（logo 方块 + 标题 + 副标题）
- 新手引导条（浅蓝胶囊 + 知道了）
- 剪贴板检测横幅（可关闭）
- 描边输入卡（OutlinedTextField + 实心按钮）
- 「最近记录」3 条缩略图行
- 页脚：平台徽标 4 枚 + 说明文字

**新设计（After）**
1. **Hero 压缩为「品牌条」**：高度减半，白底上放小号渐变 logo + 「链取」，右侧可直进设置；副标题与平台列表不再重复展示。
2. **输入区升级为主焦点**：
   - 背景换成 `surfaceTinted` 淡层（无描边无阴影），内部输入框**去描边**（透明底 + 底部细线或直接填充），整体更像「一张工作台」而非「一张卡片」；
   - 按钮保持实心品牌蓝胶囊，宽度收窄至内容自适应并居中或靠右；
   - 输入框下方常驻一行**平台彩点胶囊**（4 平台小圆点 + 名称），一屏内唯一一次「支持哪些平台」。
3. **剪贴板横幅保留**，但样式改为「浅蓝软胶囊 + 平台彩点」，与输入区层级分开。
4. **引导条**：移入设置页首项（「使用提示」）或换成输入框下一条 12sp 灰字，删除浅蓝胶囊条，首屏降噪。
5. **最近记录**：保留（这是首屏的「实物」），缩略图 44→48dp、信息行更紧凑。
6. **页脚精简**：只留一句版本/说明，平台徽标行整体移除（已在输入区表达）。

**交互**：输入框聚焦时，「开始解析」按钮从灰→蓝渐变放大（scale 1.0→1.03 的微动效）；粘贴检测横幅入场方向与 Hero 强度错开。

### 4.2 解析结果 Result

**现状（Before）**
- TopAppBar（返回 + 解析结果 + 复制链接）
- 信息头：徽标 + 标题 + 元信息行 + 满宽分隔线
- 视频（9:16 限高、右上角保存浮标）、图片网格 2dp 间隙「相册式」
- 底部操作条：进度文案 + 进度条 + 「全部保存」实心按钮
- Live 徽章（蓝底胶囊）

**新设计（After）**
1. **信息头降噪**：平台身份改为「彩点 + 名称」轻量行；标题正文化（bodyLarge），去掉满宽分隔线，改用留白分组。
2. **媒体区微调**：
   - 图片网格圆角 4dp → 保留 4dp（相册式不变），但每张图 hover/按下时缩放 1.02 给出「可选」暗示；
   - Live 徽章改为「彩点 + Live」或右上角小动图图标，颜色从品牌蓝改为平台彩点派生色（区分于主按钮）。
3. **下载交互统一**：单图/单视频保存浮标画法统一（34dp 半透明圆 + 下载箭头），下载中变进度环，完成变对勾（现有逻辑保留）；视觉上镀一层「微光」动画。
4. **底部操作条**升级为「悬浮胶囊栏」（圆角 24dp Surface + tonalElevation）：
   - 收起态：仅「全部保存 n」胶囊按钮；
   - 下载态：进度环 + 数字 n/m + 取消/重试入口；
   - 顶部超出时自动出现，不给页面留死高度。
5. **全屏预览**：底部加一细条缩略图轨（当前页/总数），手势左右滑动切换（保留现有预览能力，仅增强展示）。

### 4.3 历史 History

**现状（Before）**
- 页头（历史记录 + 选择）
- 5 个 FilterChip（全部/小红书/抖音/微博/X + 数字）
- 按日吸顶分组标题（今天/昨天/M月d日）
- 记录卡：64dp 封面 + 标题 + 类型 Tag + 时间 + 更多菜单(三点)

**新设计（After）**
1. **筛选条轻量化**：Chip 改为「文字 + 彩点」胶囊（选中时品牌容器色不变但更紧凑），数字用等宽字体；
2. **分组标题更安静**：去掉吸顶的「黑字条」感，改为「今天 / 昨天」小号灰字+细引线（沿用 SectionHeader 语言）；
3. **记录卡**：
   - 封面 64→72dp，圆角 `small`；
   - 右上角状态：已保存媒体数用「N ✓」小标记（替代/并行 TypeTag），平台身份用封面右下角彩点；
   - 长按进多选保留；多选时封面外圈出现环形选中样式（替代方形内勾）。
4. **下拉菜单**保留（重新解析/删除），但图标从「三点」改为「圆点更多」更轻。

### 4.4 设置 Settings

**现状（Before）**
- 分区卡片：解析方式（Switch）/ 自建服务器 / 平台 Cookie × 3
- 吸底保存条（状态点 + 保存设置）

**新设计（After）**
1. **分组样式改为「无边框淡层分组」**：每组分一块 `surfaceTinted` 圆角面板，组内行之间用细线分隔（iOS 设置风格），不再每行一张卡。
2. **行组件统一**：图标圆块(32dp) + 标题 + 描述(可折叠) + Switch/箭头；平台 Cookie 行沿用「状态点 + 已配置/未配置」，但颜色点从绿/灰改为平台彩点 + 文字状态。
3. **吸底保存条**：按钮改为低调「Tonal」大圆角，状态文案并入按钮旁小点（未保存=琥珀、已保存=品牌蓝对勾），削弱「保存按钮」的压迫感，仍常驻。
4. 版本信息置于页尾居中，保持。

## 5. 动效与微交互（不新增功能，只增强反馈）

| 位置 | 动效 | 时长 |
| --- | --- | --- |
| 页面切换 | 保留 ScreenFadeIn（180ms 淡入 + 4dp） | 现有 |
| 主按钮 | 按压 scale 0.98，可用性状态色平滑过渡 | ≤120ms |
| 下载进度 | 数值用 `tnum` 等宽防抖动（现有）+ 完成时对勾弹性入场（现有） | 现有 |
| 图片点击预览 | 1.05 轻微放大动画再进入全屏 | ≤160ms |
| 悬浮保存栏 | 出现时从底部上滑 12dp 淡入；隐藏时下滑淡出 | 180ms |

> 遵守 `prefers-reduced-motion`：系统关闭动画时全部退化为无动画直切。

---

## 6. 无障碍与一致性保持

- 对比度：所有新增色仍遵循 AA（正文 4.5:1、大字 3:1），彩点只作装饰不作信息唯一载体；
- 读屏：所有新图标带 contentDescription；悬浮操作栏保留语义文案；
- 平台色 = 身份，品牌蓝 = 动作：两种含义界限不变（沿用现有 Color.kt 注释约定）；
- 大字体（fontScale ≥1.3）：悬浮栏与 Hero 自动换行堆叠，不裁切。
